# 糖豆人探索の主宰官方网站

这里是「糖豆人探索の主宰」的官方网站，将历年每一场活动的记录都收在一起：
活动信息、实绩、测评、考勤、资源、日程，还有热点帖子、评论和表情包。

---

## 一、第一次打开网站

1. 打开网页，先看到当前最新活动标志和一行英文提示「PRESS ANY BUTTON」。
2. 按任意键、或者点一下画面，就会开始播放开场动画（素材来源于Ubisoft发行的Assassin's Creed® Shadows）。
3. 开场动画放完，就正式进入网站。

刚进来时你的身份是**访客**，暂时所有内容都能正常浏览。

---

## 二、页面分为几块

| 位置 | 内容 |
| --- | --- |
| 左上角 | 你的头像、昵称、称号、等级。头像点一下打开暂停界面；点昵称直接进「切换账号」；点称号直接进「切换称号」 |
| 正上方 | 三个栏目按钮：**商店**、**资源**、**热点** |
| 右上角 | 正在播放的音乐名称和封面。点歌名可以直接跳到设置页的「音频」 |
| 最下方 | 一排活动图标，像收音机的刻度一样，选中的那个会变大一格 |

如果浏览器窗口比较窄，网站会自动换成两列：

- **商店**：左边是实绩，右列是一张卡片，详情和测评依次排在卡片里。
- **资源**：左边是浏览和日程，点右上角箭头可以切换；右边是观赏。
- **热点**：左边是标题，右边用上方的「内容 / 评论」切换。

再窄一些、接近折叠屏内屏比例时，两列会变成 1:2，顶部导航会变成液态玻璃胶囊。 顶部导航的选中胶囊可以拖动，只有胶囊覆盖到的文字会变粉色；长按时选中胶囊可以超出外层导航。

继续缩窄到手机竖屏比例时，会进入更简洁的单列外屏模式：顶部显示当前活动标志，栏目导航移到页面底部。商店按“详情 → 实绩 → 测评”排列；资源页先显示浏览列表，点资源后进入观赏页；热点页先显示标题列表，点标题后进入内容和评论页，二级页左上角都有返回按钮。

---

## 三、切换活动

底下的那一排图标，每一个代表一场活动。选中哪一场，整个网站就会换成那一场的内容。

- **用鼠标**：滚轮上下滚，或者按住往左右拖，也可以直接点两边的图标。
- **用键盘**：按 `A` 看上一场，按 `D` 看下一场。
- **用手柄**：按手柄上的扳机键换活动。

换活动的时候，背景壁纸、背景音乐、三个栏目里的内容都会一起换成新的。

---

## 四、商店（活动主页）

这里是一场活动的总览，分三部分：

### 详情
- 活动的中文名、开发商、发行商、发行日、标签类别、共有几个版本。
- **购买信息**：有哪些版本、有哪些追加内容，各自的价格，以及你有没有拥有。
  - 按钮上会写「已拥有 / 未拥有 / 已包含」，一眼就能看出情况。
  - 还没上线的活动，按钮会显示「预购」。
- **持有名单**：提示条会写着持有情况，点一下就能看到哪些成员拥有这场活动，都出勤了哪些版本或追加内容。

### 实绩
- 如果这场活动有实绩组，会先看到总览，点进去才是每一条实绩。
- 实绩按稀有程度用颜色区分，从低到高：青铜、白银、黄金、铂金、紫金、幻彩。

### 测评
- 各个机构给出的分数，分数高低用不同颜色表示，上方还有分数分布。
- 点任意一条，可以看完整测评文字，再点左上角的箭头返回。
- 如果一场活动分成原版、重制、DLC 等类别，会一页一页分开显示；左右上角的箭头用来翻到前一类或后一类。

---

## 五、资源

- **浏览**：这场活动的图片素材列表，点任意一张就是选中它。
- **观赏**：右边的大图区域会显示当前选中的图片。
- **日程**：上面是日历，有安排的日期会被标出来；下面是按顺序排好的每一场安排，还会提示「今天」「3天前」这样的时间。

有的活动还带**小游戏**，「资源」页面上方会出现进入按钮。比如「2026糖豆人拜年纪」里的打地鼠：
30 秒内打中越多越好，越到后面出现得越快，时间结束后会给出分数。

---

## 六、热点

分成三栏：

- **标题**：上面是搜索框和关键词胶囊，输入文字就能筛选帖子；下面是帖子列表。
- **内容**：选中帖子的完整内容。
- **评论**：这条帖子的评论和回复。
  - 右上角两个按钮可以切换「按时间排序」还是「按热度排序」，以及正序倒序。
  - 一条评论下面的回复最多显示三条，点一下可以展开看全部。

---

## 七、账号与个人资料

- 不登录也能看全部内容，只是显示为「访客用户」。（访客权限将在后续降低）
- 点左上角头像 → **用户切换**，输入自己的账号和密码就能登录。（访客无法自主注册账号，只能联系糖豆人玩家“煎炸的豬”请求认证与账号。）
- 登录后，左上角会显示你的昵称、头像、称号和等级，等级旁边还有经验条。
- 点侧边栏里的**称号**，可以挑一个自己喜欢的称号戴上；不挑的话会显示等级最高的那个。
- 称号页里还有**成就称号**：等级榜、价值榜、发言榜各六档（从青铜到幻彩）。达到要求就会自动出现在称号列表里，和普通称号一样可以挑选；不需要导入任何文件，没达到的不会显示。
- 想退出，点侧边栏里的**退出登录**。

---

## 八、音乐播放

- 右上角的封面：点一下就是播放或暂停。
- 沿着封面外圈那个圆环拖动，可以快进、快退。
- 每场活动有自己的音乐，换活动就自动换成新的。
- 点右上角的歌名，会直接打开设置页并停在「音频」那一栏，方便调音量。

---

## 九、设置

按 `I` 键，或者点侧边栏里的**设置**，可以打开设置页。里面分六类：

- **界面**：壁纸亮度、卡片模糊程度、沉浸光效（一共 4 档，调到 0 就没有光效了）。
- **显示**：性能模式（觉得卡就打开）、整体画质（极低到极高），还可以给壁纸、头像与音乐、实绩、徽标、资源、表情包分别设置画质。
- **控制**：把键盘快捷键改成自己顺手的按键。
- **音频**：主音量、迷你游戏音量。
- **字体**：四种字体任选，点一下即可预览和切换。
- **赞助**：点开可以看微信、支付宝的收款码。

---

## 十、键盘与手柄

默认的键盘操作：

| 按键 | 作用 |
| --- | --- |
| `A` / `D` | 上一场 / 下一场活动 |
| `Q` / `E` | 上一个 / 下一个栏目 |
| `X` | 音乐播放或暂停 |
| `Z` / `C` | 音乐快退 / 快进 |
| `Tab` | 隐藏或显示界面（专心看页面时可以按） |
| `I` | 打开设置 |
| `Esc` | 打开或关闭暂停菜单 |

插上手柄也能用，按键会适配为 Xbox 或 PlayStation 的模式。

---

## 十一、暂停菜单里的排行榜

按 `Esc` 打开暂停菜单，右边有三个榜单：

右上角会显示网站累计使用的 Token 和花费金额。

- **老登等级榜**：谁的经验和等级最高。
- **全勤价值榜**：谁的收藏价值最高。
- **水军发言榜**：谁在评论里写的字最多。

排在第一名的那条会单独高亮出来。

这三个榜单也对应成就称号：等级、价值、发言字数达到要求，就会自动拿到对应的称号。

---

## 十二、小提示

- 从首页顶栏点进去的页面（切换账号 / 切换称号 / 设置），点返回会直接回到首页；从暂停菜单点进去的，返回会回到暂停菜单。
- 卡片里的长文字会自动收成一行并显示省略号；鼠标移上去会循环滚动，第一次在第一个字停 1 秒，之后每轮停 3 秒再继续。
- 手机、平板也能用；折叠屏内屏里，点右上角当前活动图标，可上下滑动活动列表，滑到中间刻度后点一下选中。
- 浏览器标签页上的名字会跟着当前活动变化：没选活动时是「糖豆人探索の主宰」，选了活动就变成「活动名 - 糖豆人探索の主宰」。
- 标签页上的小图标就是网站的图标。
- 你调过的亮度、画质、字体、音量、快捷键会记住，下次打开还是你设置的样子。
