## 一、安装与启动

1. 下载安装包，一路点「立即安装」即可，可以自己改安装位置。
2. 打开 FGEXPIG：先下载并校验资源（底部会显示进度），完成后进入壁纸幻灯片**主菜单**。
3. 主菜单四个按钮：**Main Story**（进网站）、**Website**（官网）、**GitHub Repository**、**Exit**。
4. 点 **Main Story**：播放开场动画，然后进入首页。之后想回主菜单，从右上角菜单里选「退出至菜单」。

---

## 二、界面分区

| 位置 | 内容 |
| --- | --- |
| 左上角 | 正在播放的音乐：封面 + 歌名 |
| 正上方 | 三个栏目：**商店**、**资源**、**热点** |
| 右上角 | 菜单按钮（设置、退出至菜单）、最小化、关闭 |
| 最下方 | 一排活动图标，像刻度盘一样，选中的那格会稍微放大 |

---

## 三、三个栏目

### 商店（活动主页）
- **详情**：活动中文名、开发商、发行商、发行日、标签类别、版本数量；每个版本与追加内容的名称、价格和所有地图代码。
- **实绩**：按稀有度分色 —— 青铜、白银、黄金、铂金、紫金、幻彩；带奖杯组的会先显示总览。
- **测评**：各机构评分（按分数上色，附分数分布），点开看完整测评；分原版 / 重制 / DLC 时用左右箭头翻页。

### 资源
- **浏览 / 观赏**：点左边的素材，右边大图显示。
- **日程**：日历标出有安排的日期，下面按顺序列出安排，并显示「今天」「3 天前」这样的相对时间。

### 热点
- **标题**：搜索框 + 关键词胶囊筛选，下面是帖子列表。
- **内容 / 评论**：浏览帖子正文。

## 四、切换活动

底部每一格是一场活动，选中后背景壁纸、背景音乐和三个栏目的内容会一起换掉。

| 方式 | 操作 |
| --- | --- |
| 鼠标 | 滚轮上下滚、按住左右拖，或直接点两边的图标 |
| 键盘 | `A` 上一场 / `D` 下一场 |
| 手柄 | `LT` / `RT`（Xbox）、`L2` / `R2`（PlayStation） |

活动多的时候按 `空格` 打开**活动中心**，可以按年份、开发商筛选。

---

## 五、音乐

- 点左上角封面：播放 / 暂停；沿封面外圈的圆环拖动：快退 / 快进。
- 每场活动有自己的音乐，换活动自动换。
- 点歌名会直接跳到设置里的「音频」调音量。

---

## 六、窗口

窗口比例与窗口大小都固定，不能用鼠标拖窗口边缘改：

| 设置项 | 可选值 |
| --- | --- |
| 窗口比例 | 16:9 / 16:10 |
| 窗口大小 | 极小 / 小 / 中等 / 大 / 极大 |

在「设置 → 界面」里用左右箭头切换。窗口右上角有最小化与关闭按钮。

---

## 七、设置

按 `I`，或从右上角菜单进入。

| 分类 | 内容 |
| --- | --- |
| 界面 | 窗口比例、窗口大小、亮度、模糊度、沉浸光效（0–3 级） |
| 控制 | 自定义快捷键：点按键框后按下新键即可，重复会与旧键交换 |
| 音频 | 主音量、小游戏音量 |
| 字体 | 四种字体，点了立即预览切换 |
| 语言 | 简体中文、繁體中文、English、日本語、한국어、Français、Italiano、Deutsch、Español、Português、Русский、Polski |
| 赞助 | 微信、支付宝、PayPal 收款码 |

---

## 八、快捷键

| 按键 | 作用 |
| --- | --- |
| `A` / `D` | 上一场 / 下一场活动 |
| `Q` / `E` | 上一个 / 下一个栏目 |
| `X` | 音乐播放或暂停 |
| `Z` / `C` | 音乐快退 / 快进 |
| `空格` | 活动中心 |
| `V` | 更新日志 |
| `Tab` | 隐藏 / 显示界面 |
| `I` | 设置 |
| `Esc` | 返回 / 关闭当前页 |

插上手柄会自动适配 Xbox 与 PlayStation 的按键图标，也可以在设置里手动切换。

---

## 九、小提示

- 可以浏览全部活动资料；评论与部分数据只展示一部分。
- 卡片里的长文字会自动收成一行并显示省略号，鼠标移上去会滚动查看。
- 语言、亮度、字体、音量、快捷键、窗口大小都会记住，下次打开还是你设置的样子。
- 窗口标题固定为「FGEXPIG」，任务栏图标就是那只绿皮猪。是的没错，作为本网站与应用程序的创始者，喜欢在糖豆人中穿绿色猪猪装扮，相信你一定在游戏中见过绿猪巨星。
