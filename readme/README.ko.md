## 1. 설치 및 실행

1. 설치 파일을 내려받아 「설치」만 계속 누르면 완료됩니다. 설치 위치는 직접 바꿀 수 있습니다.
2. FGEXPIG를 열면 먼저 리소스를 내려받고 검증합니다(화면 아래에 진행률 표시). 완료되면 배경화면 슬라이드쇼 **메인 메뉴**로 들어갑니다.
3. 메인 메뉴의 네 개 버튼: **Main Story**(사이트로), **Website**(공식 사이트), **GitHub Repository**, **Exit**.
4. **Main Story**를 누르면 오프닝 애니메이션이 재생되고 홈페이지로 들어갑니다. 메뉴로 돌아가려면 오른쪽 위 메뉴에서 「메뉴로 나가기」를 고릅니다.

## 2. 화면 구성

| 위치 | 내용 |
| --- | --- |
| 왼쪽 위 | 재생 중인 음악: 커버 + 곡명 |
| 가운데 위 | 세 개의 탭: **상점**, **리소스**, **핫** |
| 오른쪽 위 | 메뉴 버튼(설정, 메뉴로 나가기), 최소화, 닫기 |
| 맨 아래 | 이벤트 아이콘 한 줄. 다이얼처럼 선택된 칸이 조금 커집니다 |

## 3. 세 개의 탭

### 상점(이벤트 홈)
- **상세**: 이벤트 중국어명, 개발사, 배급사, 출시일, 태그, 버전 수. 각 버전과 추가 콘텐츠의 이름·가격·모든 맵 코드.
- **업적**: 희귀도에 따라 색 구분 —— 브론즈, 실버, 골드, 플래티넘, 자금, 무지개. 트로피 그룹이 있으면 먼저 개요를 보여줍니다.
- **평가**: 각 기관 점수(점수에 따라 색 구분, 분포 포함). 클릭하면 전체 평가를 볼 수 있고, 원판 / 리마스터 / DLC로 나뉘면 좌우 화살표로 넘깁니다.

### 리소스
- **둘러보기 / 감상**: 왼쪽 자료를 클릭하면 오른쪽에 크게 표시됩니다.
- **일정**: 달력에 일정이 있는 날짜가 표시되고, 아래에 순서대로 나열되며 「오늘」「3일 전」같은 상대 시간이 함께 표시됩니다.

### 핫
- **제목**: 검색창 + 키워드 칩으로 걸러내고, 아래에 게시글 목록.
- **내용 / 댓글**: 게시글 본문을 봅니다.

## 4. 이벤트 전환

아래 한 칸이 하나의 이벤트입니다. 선택하면 배경화면, 배경 음악, 세 탭의 내용이 모두 바뀝니다.

| 방법 | 동작 |
| --- | --- |
| 마우스 | 휠로 위아래, 누른 채 좌우로 드래그, 또는 양쪽 아이콘 클릭 |
| 키보드 | `A` 이전 이벤트 / `D` 다음 이벤트 |
| 게임패드 | `LT` / `RT`(Xbox), `L2` / `R2`(PlayStation) |

이벤트가 많을 때는 `스페이스`를 눌러 **활동 센터**를 열고 연도·개발사로 걸러낼 수 있습니다.

---

## 5. 음악

- 왼쪽 위 커버 클릭: 재생 / 일시정지. 커버 바깥쪽 링 드래그: 되감기 / 빨리 감기.
- 이벤트마다 음악이 있고, 이벤트를 바꾸면 자동으로 바뀝니다.
- 곡명을 클릭하면 설정의 「오디오」로 바로 이동해 음량을 조절할 수 있습니다.

---

## 6. 창

창 비율과 창 크기는 고정이며, 마우스로 창 가장자리를 끌어 바꿀 수 없습니다:

| 설정 항목 | 선택값 |
| --- | --- |
| 창 비율 | 16:9 / 16:10 |
| 창 크기 | 매우 작음 / 작음 / 중간 / 큼 / 매우 큼 |

「설정 → 인터페이스」에서 좌우 화살표로 바꿉니다. 창 오른쪽 위에 최소화와 닫기 버튼이 있습니다.

---

## 7. 설정

`I`를 누르거나 오른쪽 위 메뉴에서 엽니다.

| 분류 | 내용 |
| --- | --- |
| 인터페이스 | 창 비율, 창 크기, 밝기, 흐림, 몰입 광효과(0–3단계) |
| 조작 | 단축키 설정: 키 상자를 클릭한 뒤 새 키를 누르면 됩니다. 중복되면 기존 키와 교체됩니다 |
| 오디오 | 주 음량, 미니게임 음량 |
| 글꼴 | 네 가지 글꼴, 클릭하면 바로 미리보기와 전환 |
| 언어 | 简体中文、繁體中文、English、日本語、한국어、Français、Italiano、Deutsch、Español、Português、Русский、Polski |
| 후원 | WeChat, Alipay, PayPal QR 코드 |

## 8. 단축키

| 키 | 동작 |
| --- | --- |
| `A` / `D` | 이전 / 다음 이벤트 |
| `Q` / `E` | 이전 / 다음 탭 |
| `X` | 음악 재생 / 일시정지 |
| `Z` / `C` | 음악 되감기 / 빨리 감기 |
| `스페이스` | 활동 센터 |
| `V` | 업데이트 로그 |
| `Tab` | HUD 숨기기 / 표시 |
| `I` | 설정 |
| `Esc` | 뒤로 / 현재 페이지 닫기 |

게임패드를 연결하면 버튼 아이콘이 Xbox / PlayStation에 맞게 자동으로 바뀝니다. 설정에서 수동으로 바꿀 수도 있습니다.

## 9. 팁

- 모든 이벤트 자료를 볼 수 있습니다. 댓글과 일부 데이터는 일부분만 표시됩니다.
- 카드의 긴 텍스트는 자동으로 한 줄로 줄고 말줄임표가 붙습니다. 마우스를 올리면 스크롤해서 볼 수 있습니다.
- 언어, 밝기, 글꼴, 음량, 단축키, 창 크기는 기억되어 다음에 열어도 그대로입니다.
- 창 제목은 항상 「FGEXPIG」이고 작업 표시줄 아이콘은 그 초록 돼지입니다. 맞습니다, 이 웹사이트와 앱의 제작자는 Fall Guys에서 초록 돼지 의상을 즐겨 입기 때문에, 게임에서 그 초록 돼지 슈퍼스타를 본 적이 있을 겁니다.
