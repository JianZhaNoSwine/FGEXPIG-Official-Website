## 1. Install and launch

1. Download the installer and click "Install" all the way through — you can pick your own install location.
2. Open FGEXPIG: it downloads and verifies resources first (progress at the bottom of the screen), then enters the wallpaper-slideshow **main menu**.
3. The main menu has four buttons: **Main Story** (open the site), **Website** (official site), **GitHub Repository**, **Exit**.
4. Click **Main Story**: the opening animation plays, then the home page appears. To go back to the menu, pick "Exit to Menu" from the top-right menu.

---

## 2. Screen layout

| Position | Contents |
| --- | --- |
| Top-left | The music that is playing: cover + track title |
| Top-center | Three tabs: **Shop**, **Resources**, **News** |
| Top-right | Menu button (Settings, Exit to Menu), Minimize, Close |
| Bottom | A row of event icons, like a dial; the selected one is slightly larger |

---

## 3. The three tabs

### Shop (event home)
- **Details**: Chinese name, developer, publisher, release date, tags, number of versions; every version and add-on with its name, price and all map codes.
- **Achievements**: color-coded by rarity — Bronze, Silver, Gold, Platinum, Purple-Gold, Iridescent; events with trophy groups show an overview first.
- **Reviews**: outlet scores (color-coded, with a score distribution); click one to read the full review; when an event is split into original / remaster / DLC, use the left and right arrows to page through.

### Resources
- **Browse / Viewer**: click an item on the left, the big picture shows on the right.
- **Schedule**: the calendar marks the days that have entries; below, every entry is listed in order, with relative times such as "Today" and "3 days ago".

### News
- **Titles**: search box + keyword chips, with the post list below.
- **Content / Comments**: read the post text.

## 4. Switching events

Each slot at the bottom is one event; selecting it swaps the wallpaper, the music and the contents of all three tabs.

| Input | Action |
| --- | --- |
| Mouse | Scroll up/down, drag left/right, or click the icons on either side |
| Keyboard | `A` previous / `D` next |
| Gamepad | `LT` / `RT` (Xbox), `L2` / `R2` (PlayStation) |

When there are many events, press `Space` to open the **Activity Center** and filter by year or developer.

---

## 5. Music

- Click the cover in the top-left corner: play / pause; drag the ring around the cover: rewind / fast-forward.
- Every event has its own music, and it switches automatically with the event.
- Click the track title to jump straight to the "Audio" tab in the settings and adjust the volume.

---

## 6. Window

Both the window ratio and the window size are fixed — you cannot change them by dragging the window edges:

| Setting | Values |
| --- | --- |
| Window ratio | 16:9 / 16:10 |
| Window size | Tiny / Small / Medium / Large / Extra large |

Change them with the left and right arrows in "Settings → Interface". The top-right corner of the window has minimize and close buttons.

---

## 7. Settings

Press `I`, or open them from the top-right menu.

| Tab | Contents |
| --- | --- |
| Interface | Window ratio, window size, brightness, blur, immersive light (levels 0–3) |
| Controls | Custom keybinds: click a key box and press a new key; duplicates swap with the old key |
| Audio | Main volume, minigame volume |
| Font | Four fonts — click to preview and switch instantly |
| Language | 简体中文, 繁體中文, English, 日本語, 한국어, Français, Italiano, Deutsch, Español, Português, Русский, Polski |
| Sponsor | WeChat / Alipay / PayPal QR codes |

## 8. Shortcuts

| Key | Action |
| --- | --- |
| `A` / `D` | Previous / next event |
| `Q` / `E` | Previous / next tab |
| `X` | Play or pause music |
| `Z` / `C` | Rewind / fast-forward music |
| `Space` | Activity Center |
| `V` | Update log |
| `Tab` | Hide / show the HUD |
| `I` | Settings |
| `Esc` | Back / close the current page |

Plug in a gamepad and the button icons adapt to Xbox or PlayStation automatically; you can also switch them manually in the settings.

---

## 9. Tips

- You can browse all of an event's materials; comments and some data are only partially shown.
- Long text in cards collapses to a single line with an ellipsis — hover over it to scroll through.
- Language, brightness, font, volume, keybinds and window size are all remembered; next time you open it, everything is as you left it.
- The window title is always "FGEXPIG", and the taskbar icon is that green pig. Yes, really — as the founder of this website and app I like wearing the green pig outfit in Fall Guys, so you have probably met the green pig superstar in game.
