## 1. Installation et lancement

1. Téléchargez l'installateur et cliquez sur « Installer » jusqu'au bout — vous pouvez choisir l'emplacement d'installation.
2. Ouvrez FGEXPIG : il télécharge et vérifie d'abord les ressources (progression en bas de l'écran), puis arrive sur le **menu principal** en diaporama de fonds d'écran.
3. Le menu principal propose quatre boutons : **Main Story** (ouvrir le site), **Website** (site officiel), **GitHub Repository**, **Exit**.
4. Cliquez sur **Main Story** : l'animation d'ouverture se lance, puis la page d'accueil s'affiche. Pour revenir au menu, choisissez « Quitter vers le menu » dans le menu en haut à droite.

---

## 2. Disposition de l'écran

| Position | Contenu |
| --- | --- |
| En haut à gauche | La musique en cours : pochette + titre |
| En haut au centre | Trois onglets : **Boutique**, **Ressources**, **Tendances** |
| En haut à droite | Bouton menu (Paramètres, Quitter vers le menu), Réduire, Fermer |
| En bas | Une rangée d'icônes d'événements, comme un cadran : la sélection est légèrement agrandie |

---

## 3. Les trois onglets

### Boutique (accueil de l'événement)
- **Détails** : nom chinois, développeur, éditeur, date de sortie, mots-clés, nombre de versions ; chaque version et contenu additionnel avec son nom, son prix et tous les codes de carte.
- **Succès** : colorés selon la rareté — Bronze, Argent, Or, Platine, Violet-or, Iridescent ; les événements avec des groupes de trophées affichent d'abord une vue d'ensemble.
- **Critiques** : notes des médias (colorées selon la note, avec la répartition) ; cliquez pour lire la critique complète ; quand l'événement est divisé en original / remaster / DLC, utilisez les flèches gauche et droite pour changer de page.

### Ressources
- **Parcourir / Visionneuse** : cliquez sur un élément à gauche, la grande image s'affiche à droite.
- **Calendrier** : le calendrier signale les jours qui ont des entrées ; en dessous, chaque entrée est listée dans l'ordre, avec des temps relatifs comme « Aujourd'hui » et « il y a 3 jours ».

### Tendances
- **Titres** : champ de recherche + puces de mots-clés, avec la liste des posts en dessous.
- **Contenu / Commentaires** : consultez le texte du post.

---

## 4. Changer d'événement

Chaque case en bas correspond à un événement ; la sélectionner change le fond d'écran, la musique et le contenu des trois onglets.

| Entrée | Action |
| --- | --- |
| Souris | Molette haut/bas, glisser en maintenant le clic, ou cliquer sur les icônes sur les côtés |
| Clavier | `A` précédent / `D` suivant |
| Manette | `LT` / `RT` (Xbox), `L2` / `R2` (PlayStation) |

Quand il y a beaucoup d'événements, appuyez sur `Espace` pour ouvrir le **Centre d'activités** et filtrer par année ou par développeur.

---

## 5. Musique

- Cliquez sur la pochette en haut à gauche : lecture / pause ; faites glisser l'anneau autour de la pochette : rembobiner / avancer.
- Chaque événement a sa propre musique, changée automatiquement avec l'événement.
- Cliquez sur le titre pour ouvrir directement l'onglet « Audio » des paramètres et régler le volume.

---

## 6. Fenêtre

Le format et la taille de la fenêtre sont fixes : impossible de les modifier en tirant sur les bords :

| Réglage | Valeurs |
| --- | --- |
| Format de fenêtre | 16:9 / 16:10 |
| Taille de la fenêtre | Très petite / Petite / Moyenne / Grande / Très grande |

Modifiez-les avec les flèches gauche et droite dans « Paramètres → Interface ». Les boutons Réduire et Fermer sont en haut à droite de la fenêtre.

---

## 7. Paramètres

Appuyez sur `I`, ou ouvrez-les depuis le menu en haut à droite.

| Catégorie | Contenu |
| --- | --- |
| Interface | Format de fenêtre, taille de la fenêtre, luminosité, flou, effet lumineux immersif (niveaux 0–3) |
| Commandes | Raccourcis personnalisés : cliquez sur une case puis appuyez sur une nouvelle touche ; en cas de doublon, les touches sont échangées |
| Audio | Volume principal, volume des mini-jeux |
| Police | Quatre polices, cliquez pour prévisualiser et changer immédiatement |
| Langue | 简体中文, 繁體中文, English, 日本語, 한국어, Français, Italiano, Deutsch, Español, Português, Русский, Polski |
| Soutenir | Codes QR WeChat / Alipay / PayPal |

---

## 8. Raccourcis

| Touche | Action |
| --- | --- |
| `A` / `D` | Événement précédent / suivant |
| `Q` / `E` | Onglet précédent / suivant |
| `X` | Lecture ou pause de la musique |
| `Z` / `C` | Rembobiner / avancer la musique |
| `Espace` | Centre d'activités |
| `V` | Journal des mises à jour |
| `Tab` | Afficher / masquer l'interface |
| `I` | Paramètres |
| `Esc` | Retour / fermer la page en cours |

Branchez une manette : les icônes s'adaptent automatiquement à Xbox ou PlayStation, et vous pouvez aussi les changer manuellement dans les paramètres.

---

## 9. Astuces

- Vous pouvez parcourir toutes les ressources des événements ; les commentaires et certaines données ne sont que partiellement affichés.
- Les textes longs des cartes sont réduits à une ligne avec des points de suspension ; survolez-les pour les faire défiler.
- Langue, luminosité, police, volume, raccourcis et taille de fenêtre sont mémorisés : à la prochaine ouverture, tout est comme vous l'avez laissé.
- Le titre de la fenêtre est toujours « FGEXPIG » et l'icône de la barre des tâches est ce cochon vert. Eh oui : en tant que créateur de ce site et de cette application, j'aime porter la tenue du cochon vert dans Fall Guys — vous avez donc sûrement déjà croisé la superstar cochon vert en jeu.
