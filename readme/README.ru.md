## 1. Установка и запуск

1. Скачайте установщик и просто нажимайте «Установить» — папку установки можно выбрать самому.
2. Откройте FGEXPIG: сначала программа загружает и проверяет ресурсы (прогресс показан внизу экрана), затем открывается **главное меню** со слайд-шоу обоев.
3. В главном меню четыре кнопки: **Main Story** (открыть сайт), **Website** (официальный сайт), **GitHub Repository**, **Exit**.
4. Нажмите **Main Story**: проигрывается вступительная анимация и открывается главная страница. Чтобы вернуться в меню, выберите «Выйти в меню» в меню справа вверху.

## 2. Расположение на экране

| Позиция | Содержимое |
| --- | --- |
| Слева вверху | Играющая музыка: обложка + название |
| По центру вверху | Три вкладки: **Магазин**, **Ресурсы**, **Горячее** |
| Справа вверху | Кнопка меню (Настройки, Выйти в меню), Свернуть, Закрыть |
| Внизу | Ряд иконок событий, как шкала: выбранное чуть крупнее |

## 3. Три вкладки

### Магазин (главная страница события)
- **Подробности**: китайское название, разработчик, издатель, дата выхода, теги, число версий; каждая версия и дополнение с названием, ценой и всеми кодами карт.
- **Достижения**: окрашены по редкости — Бронза, Серебро, Золото, Платина, Фиолетово-золотой, Радужный; у событий с группами трофеев сначала показывается обзор.
- **Обзоры**: оценки изданий (окрашены по баллам, с распределением); нажмите, чтобы прочитать полный обзор; если событие разделено на оригинал / ремастер / DLC, переключайте страницы стрелками влево и вправо.

### Ресурсы
- **Обзор / Просмотр**: нажмите на материал слева — большое изображение появится справа.
- **Расписание**: в календаре отмечены дни с событиями; ниже по порядку перечислены все пункты с относительным временем вроде «Сегодня» и «3 дня назад».

### Горячее
- **Заголовки**: поле поиска + теги ключевых слов, ниже список постов.
- **Содержание / Комментарии**: чтение текста поста.

## 4. Переключение событий

Каждая ячейка внизу — одно событие; при выборе меняются обои, музыка и содержимое всех трёх вкладок.

| Ввод | Действие |
| --- | --- |
| Мышь | Колесо вверх/вниз, перетаскивание с зажатой кнопкой или клик по иконкам по краям |
| Клавиатура | `A` предыдущее / `D` следующее событие |
| Геймпад | `LT` / `RT` (Xbox), `L2` / `R2` (PlayStation) |

Когда событий много, нажмите `Пробел`, чтобы открыть **Центр событий** и отфильтровать по году или разработчику.

---

## 5. Музыка

- Нажмите на обложку слева вверху: воспроизведение / пауза; потяните кольцо вокруг обложки: перемотка назад / вперёд.
- У каждого события своя музыка, она меняется вместе с событием.
- Нажмите на название трека, чтобы сразу перейти к вкладке «Звук» в настройках и настроить громкость.

---

## 6. Окно

Соотношение сторон и размер окна фиксированы — перетаскиванием краёв их не изменить:

| Параметр | Значения |
| --- | --- |
| Соотношение сторон окна | 16:9 / 16:10 |
| Размер окна | Очень маленький / Маленький / Средний / Большой / Очень большой |

Меняются стрелками влево и вправо в «Настройки → Интерфейс». Справа вверху окна есть кнопки «Свернуть» и «Закрыть».

---

## 7. Настройки

Нажмите `I` или откройте их из меню справа вверху.

| Раздел | Содержимое |
| --- | --- |
| Интерфейс | Соотношение сторон окна, размер окна, яркость, размытие, иммерсивный свет (уровни 0–3) |
| Управление | Свои горячие клавиши: щёлкните по полю клавиши и нажмите новую; при повторе клавиши меняются местами |
| Звук | Основная громкость, громкость мини-игр |
| Шрифт | Четыре шрифта: нажмите, чтобы сразу посмотреть и переключить |
| Язык | 简体中文, 繁體中文, English, 日本語, 한국어, Français, Italiano, Deutsch, Español, Português, Русский, Polski |
| Поддержать | QR-коды WeChat / Alipay / PayPal |

## 8. Горячие клавиши

| Клавиша | Действие |
| --- | --- |
| `A` / `D` | Предыдущее / следующее событие |
| `Q` / `E` | Предыдущая / следующая вкладка |
| `X` | Воспроизведение или пауза музыки |
| `Z` / `C` | Перемотка музыки назад / вперёд |
| `Пробел` | Центр событий |
| `V` | Журнал обновлений |
| `Tab` | Скрыть / показать интерфейс |
| `I` | Настройки |
| `Esc` | Назад / закрыть текущую страницу |

Подключите геймпад — значки кнопок автоматически подстроятся под Xbox или PlayStation; можно переключить и вручную в настройках.

## 9. Подсказки

- Можно просматривать все материалы событий; комментарии и часть данных показываются лишь частично.
- Длинный текст в карточках сворачивается в одну строку с многоточием — наведите курсор, чтобы прокрутить.
- Язык, яркость, шрифт, громкость, горячие клавиши и размер окна запоминаются: при следующем запуске всё останется как настроено.
- Заголовок окна всегда «FGEXPIG», а значок на панели задач — та самая зелёная свинья. Да-да: как создатель этого сайта и приложения, я люблю носить костюм зелёной свиньи в Fall Guys, так что вы наверняка уже встречали зелёную свинью-суперзвезду в игре.
