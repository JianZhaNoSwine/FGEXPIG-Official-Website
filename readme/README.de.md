## 1. Installation und Start

1. Installationsprogramm herunterladen und einfach „Installieren“ durchklicken – den Installationsort kannst du selbst wählen.
2. FGEXPIG öffnen: Zuerst werden Ressourcen heruntergeladen und geprüft (Fortschritt unten am Bildschirmrand), danach geht es ins **Hauptmenü** mit der Wallpaper-Diashow.
3. Das Hauptmenü hat vier Schaltflächen: **Main Story** (Website öffnen), **Website** (offizielle Seite), **GitHub Repository**, **Exit**.
4. **Main Story** drücken: Das Intro wird abgespielt, danach öffnet sich die Startseite. Zurück ins Menü geht es über „Zum Menü zurückkehren“ im Menü oben rechts.

---

## 2. Bildschirmaufteilung

| Position | Inhalt |
| --- | --- |
| Oben links | Die laufende Musik: Cover + Titel |
| Oben Mitte | Drei Tabs: **Shop**, **Ressourcen**, **Hot** |
| Oben rechts | Menü-Schaltfläche (Einstellungen, Zum Menü zurückkehren), Minimieren, Schließen |
| Ganz unten | Eine Reihe Event-Symbole wie ein Drehregler – das ausgewählte ist etwas größer |

---

## 3. Die drei Tabs

### Shop (Event-Startseite)
- **Details**: chinesischer Name, Entwickler, Publisher, Veröffentlichung, Tags, Anzahl der Versionen; jede Version und jeder Zusatzinhalt mit Name, Preis und allen Kartencodes.
- **Erfolge**: nach Seltenheit eingefärbt — Bronze, Silber, Gold, Platin, Violettgold, Schillernd; Events mit Trophäengruppen zeigen zuerst eine Übersicht.
- **Reviews**: Wertungen der Magazine (nach Punktzahl eingefärbt, mit Verteilung); anklicken, um das vollständige Review zu lesen; bei Original / Remaster / DLC mit den Pfeilen links und rechts umblättern.

### Ressourcen
- **Durchsuchen / Ansehen**: links ein Element anklicken, rechts erscheint das große Bild.
- **Zeitplan**: Der Kalender markiert Tage mit Einträgen; darunter stehen alle Einträge der Reihe nach, mit relativen Zeiten wie „Heute“ und „vor 3 Tagen“.

### Hot
- **Titel**: Suchfeld + Keyword-Chips, darunter die Beitragsliste.
- **Inhalt / Kommentare**: den Beitragstext lesen.

## 4. Events wechseln

Jedes Kästchen unten ist ein Event; beim Auswählen wechseln Hintergrundbild, Musik und die Inhalte aller drei Tabs.

| Eingabe | Aktion |
| --- | --- |
| Maus | Mausrad hoch/runter, gedrückt nach links/rechts ziehen, oder die Symbole an den Seiten anklicken |
| Tastatur | `A` vorheriges / `D` nächstes Event |
| Gamepad | `LT` / `RT` (Xbox), `L2` / `R2` (PlayStation) |

Bei vielen Events öffnet `Leertaste` das **Aktivitätszentrum**, in dem du nach Jahr oder Entwickler filtern kannst.

---

## 5. Musik

- Cover oben links anklicken: Wiedergabe / Pause; den Ring um das Cover ziehen: zurückspulen / vorspulen.
- Jedes Event hat eigene Musik, die beim Wechsel automatisch mitwechselt.
- Titel anklicken, um direkt zum Tab „Audio“ in den Einstellungen zu springen und die Lautstärke zu regeln.

---

## 6. Fenster

Fensterverhältnis und Fenstergröße sind fest – am Fensterrand ziehen ändert nichts:

| Einstellung | Werte |
| --- | --- |
| Fensterverhältnis | 16:9 / 16:10 |
| Fenstergröße | Sehr klein / Klein / Mittel / Groß / Sehr groß |

Umstellen mit den Pfeilen links und rechts unter „Einstellungen → Oberfläche“. Oben rechts im Fenster sitzen die Schaltflächen Minimieren und Schließen.

---

## 7. Einstellungen

`I` drücken oder oben rechts im Menü öffnen.

| Kategorie | Inhalt |
| --- | --- |
| Oberfläche | Fensterverhältnis, Fenstergröße, Helligkeit, Unschärfe, Immersivlicht (Stufe 0–3) |
| Steuerung | Eigene Tastenkürzel: Tastenfeld anklicken und neue Taste drücken; doppelte Tasten werden getauscht |
| Audio | Hauptlautstärke, Minispiel-Lautstärke |
| Schriftart | Vier Schriftarten – anklicken zum Vorschauen und sofortigen Wechseln |
| Sprache | 简体中文, 繁體中文, English, 日本語, 한국어, Français, Italiano, Deutsch, Español, Português, Русский, Polski |
| Unterstützen | WeChat-, Alipay- und PayPal-QR-Codes |

---

## 8. Tastenkürzel

| Taste | Aktion |
| --- | --- |
| `A` / `D` | Vorheriges / nächstes Event |
| `Q` / `E` | Vorheriger / nächster Tab |
| `X` | Musik abspielen oder pausieren |
| `Z` / `C` | Musik zurückspulen / vorspulen |
| `Leertaste` | Aktivitätszentrum |
| `V` | Update-Protokoll |
| `Tab` | HUD aus-/einblenden |
| `I` | Einstellungen |
| `Esc` | Zurück / aktuelle Seite schließen |

Ein Gamepad wird angeschlossen und die Tasten-Symbole passen sich automatisch an Xbox oder PlayStation an; in den Einstellungen lässt sich das auch manuell umstellen.

## 9. Tipps

- Alle Event-Materialien sind einsehbar; Kommentare und einige Daten werden nur teilweise angezeigt.
- Lange Texte in Karten werden auf eine Zeile mit Auslassungspunkten gekürzt – mit der Maus darüberfahren, um sie zu durchlaufen.
- Sprache, Helligkeit, Schriftart, Lautstärke, Tastenkürzel und Fenstergröße werden gemerkt: beim nächsten Öffnen ist alles wie eingestellt.
- Der Fenstertitel ist immer „FGEXPIG“, das Taskleisten-Symbol ist dieses grüne Schwein. Ja, wirklich: Als Gründer dieser Website und App trage ich in Fall Guys gern das grüne Schweinchen-Outfit, du hast den grünen Schweine-Superstar im Spiel also sicher schon getroffen.
