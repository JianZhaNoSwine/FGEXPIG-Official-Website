## 1. インストールと起動

1. インストーラーをダウンロードして、「インストール」を押していくだけで完了。インストール先は自分で変更できます。
2. FGEXPIG を起動すると、まずリソースをダウンロードして検証します（画面下部に進捗を表示）。完了すると壁紙スライドショーの**メインメニュー**に入ります。
3. メインメニューの4つのボタン：**Main Story**（サイトへ）、**Website**（公式サイト）、**GitHub Repository**、**Exit**。
4. **Main Story** を押すとオープニングアニメーションが再生され、ホームページに入ります。メニューに戻るときは、右上のメニューから「メニューに戻る」を選びます。

---

## 2. 画面構成

| 位置 | 内容 |
| --- | --- |
| 左上 | 再生中の音楽：ジャケット + 曲名 |
| 中央 | 3つのタブ：**ショップ**、**リソース**、**ホット** |
| 右上 | メニューボタン（設定、メニューに戻る）、最小化、閉じる |
| 最下部 | イベントアイコンの列。ダイヤルのように、選択中のものは少し大きく表示されます |

---

## 3. 3つのタブ

### ショップ（イベントホーム）
- **詳細**：イベントの中国語名、開発元、販売元、発売日、タグ、バージョン数。各バージョンと追加コンテンツの名称・価格・すべてのマップコード。
- **実績**：レア度で色分け —— ブロンズ、シルバー、ゴールド、プラチナ、紫金、虹彩。トロフィーグループがある場合は先に一覧を表示します。
- **レビュー**：各媒体のスコア（点数に応じて色分け、分布付き）。クリックすると全文を表示。オリジナル / リマスター / DLC に分かれる場合は、左右の矢印でページを切り替えます。

### リソース
- **閲覧 / 鑑賞**：左の素材をクリックすると、右に大きく表示されます。
- **スケジュール**：カレンダーに予定のある日が示され、下に予定が順番に並びます。「今日」「3日前」のような相対時間も表示されます。

### ホット
- **タイトル**：検索ボックス + キーワードチップで絞り込み、下に投稿一覧。
- **内容 / コメント**：投稿の本文を閲覧します。

## 4. イベントの切り替え

下部の1マスが1イベントです。選ぶと、背景の壁紙・BGM・3つのタブの内容がすべて切り替わります。

| 操作 | 内容 |
| --- | --- |
| マウス | ホイールで上下、押したまま左右にドラッグ、または両端のアイコンをクリック |
| キーボード | `A` 前のイベント / `D` 次のイベント |
| ゲームパッド | `LT` / `RT`（Xbox）、`L2` / `R2`（PlayStation） |

イベントが多いときは `スペース` で**アクティビティセンター**を開き、年や開発元で絞り込めます。

---

## 5. 音楽

- 左上のジャケットをクリック：再生 / 一時停止。ジャケットの外側のリングをドラッグ：巻き戻し / 早送り。
- イベントごとに音楽があり、イベントを切り替えると自動で変わります。
- 曲名をクリックすると、設定の「オーディオ」に直接移動して音量を調整できます。

---

## 6. ウィンドウ

ウィンドウ比率とウィンドウサイズは固定で、マウスでウィンドウの端をドラッグしても変更できません：

| 設定項目 | 選択肢 |
| --- | --- |
| ウィンドウ比率 | 16:9 / 16:10 |
| ウィンドウサイズ | 最小 / 小 / 中 / 大 / 最大 |

「設定 → インターフェース」で左右の矢印を使って切り替えます。ウィンドウ右上に最小化と閉じるボタンがあります。

---

## 7. 設定

`I` を押すか、右上のメニューから開きます。

| 分類 | 内容 |
| --- | --- |
| インターフェース | ウィンドウ比率、ウィンドウサイズ、明るさ、ぼかし、没入光エフェクト（0〜3 レベル） |
| 操作 | ショートカットの変更：キーの枠をクリックして新しいキーを押すだけ。重複した場合は元のキーと入れ替わります |
| オーディオ | メイン音量、ミニゲーム音量 |
| フォント | 4種類のフォント。クリックするとその場でプレビューと切り替えができます |
| 言語 | 简体中文、繁體中文、English、日本語、한국어、Français、Italiano、Deutsch、Español、Português、Русский、Polski |
| 支援 | WeChat、Alipay、PayPal のQRコード |

---

## 8. ショートカット

| キー | 動作 |
| --- | --- |
| `A` / `D` | 前の / 次のイベント |
| `Q` / `E` | 前の / 次のタブ |
| `X` | 音楽の再生 / 一時停止 |
| `Z` / `C` | 音楽の巻き戻し / 早送り |
| `スペース` | アクティビティセンター |
| `V` | 更新履歴 |
| `Tab` | HUDの表示 / 非表示 |
| `I` | 設定 |
| `Esc` | 戻る / 現在のページを閉じる |

ゲームパッドを接続すると、ボタンアイコンが Xbox / PlayStation に自動で対応します。設定で手動切り替えもできます。

---

## 9. ヒント

- すべてのイベント資料を閲覧できます。コメントと一部のデータは一部分のみ表示されます。
- カード内の長いテキストは自動で1行に省略され、マウスを乗せるとスクロールして確認できます。
- 言語、明るさ、フォント、音量、ショートカット、ウィンドウサイズは記憶され、次に開いたときもそのままです。
- ウィンドウタイトルは「FGEXPIG」固定、タスクバーのアイコンはあの緑のブタです。そう、このサイトとアプリの制作者は Fall Guys で緑のブタの衣装を着るのが好きなので、ゲーム内であの緑ブタのスーパースターを見かけたことがあるはずです。
