## 一、安裝與啟動

1. 下載安裝包，一路點「立即安裝」即可，可以自己改安裝位置。
2. 打開 FGEXPIG：先下載並校驗資源（底部會顯示進度），完成後進入壁紙幻燈片**主選單**。
3. 主選單四個按鈕：**Main Story**（進網站）、**Website**（官網）、**GitHub Repository**、**Exit**。
4. 點 **Main Story**：播放開場動畫，然後進入首頁。之後想回主選單，從右上角選單裡選「退出至選單」。

---

## 二、介面分區

| 位置 | 內容 |
| --- | --- |
| 左上角 | 正在播放的音樂：封面 + 歌名 |
| 正上方 | 三個欄目：**商店**、**資源**、**熱點** |
| 右上角 | 選單按鈕（設定、退出至選單）、最小化、關閉 |
| 最下方 | 一排活動圖示，像刻度盤一樣，選中的那格會稍微放大 |

---

## 三、三個欄目

### 商店（活動主頁）
- **詳情**：活動中文名、開發商、發行商、發行日、標籤類、版本數；每個版本與追加內容的名稱、價格和所有地圖代碼。
- **實績**：按稀有度分色 —— 青銅、白銀、黃金、鉑金、紫金、幻彩；帶獎盃組的會先顯示總覽。
- **測評**：各機構評分（按分數上色，附分數分佈），點開看完整測評；分原版 / 重製 / DLC 時用左右箭頭翻頁。

### 資源
- **瀏覽 / 觀賞**：點左邊的素材，右邊大圖顯示。
- **日程**：日曆標出有安排的日期，下面按順序列出安排，並顯示「今天」「3 天前」這樣的相對時間。

### 熱點
- **標題**：搜尋框 + 關鍵詞膠囊篩選，下面是貼文列表。
- **內容 / 評論**：瀏覽貼文正文。

## 四、切換活動

底部每一格是一場活動，選中後背景壁紙、背景音樂和三個欄目的內容會一起換掉。

| 方式 | 操作 |
| --- | --- |
| 滑鼠 | 滾輪上下滾、按住左右拖，或直接點兩邊的圖示 |
| 鍵盤 | A 上一場 / D 下一場 |
| 手柄 | LT / RT（Xbox）、L2 / R2（PlayStation） |

活動多的時候按 空格 打開**活動中心**，可以按年份、開發商篩選。

---

## 五、音樂

- 點左上角封面：播放 / 暫停；沿封面外圈的圓環拖動：倒轉 / 快轉。
- 每場活動有自己的音樂，換活動自動換。
- 點歌名會直接跳到設定裡的「音訊」調音量。

---

## 六、視窗

視窗比例與視窗大小都固定，不能用滑鼠拖視窗邊緣改：

| 設定項 | 可選值 |
| --- | --- |
| 視窗比例 | 16:9 / 16:10 |
| 視窗大小 | 極小 / 小 / 中等 / 大 / 極大 |

在「設定 → 介面」裡用左右箭頭切換。視窗右上角有最小化與關閉按鈕。

---

## 七、設定

按 I，或從右上角選單進入。

| 分類 | 內容 |
| --- | --- |
| 介面 | 視窗比例、視窗大小、亮度、模糊度、沉浸光效（0–3 級） |
| 操作 | 自訂快捷鍵：點按鍵框後按下新鍵即可，重複會與舊鍵交換 |
| 音訊 | 主音量、小遊戲音量 |
| 字型 | 四種字型，點了立即預覽切換 |
| 語言 | 简体中文、繁體中文、English、日本語、한국어、Français、Italiano、Deutsch、Español、Português、Русский、Polski |
| 贊助 | 微信、支付寶、PayPal 收款碼 |

---

## 八、快捷鍵

| 按鍵 | 作用 |
| --- | --- |
| A / D | 上一場 / 下一場活動 |
| Q / E | 上一個 / 下一個欄目 |
| X | 音樂播放或暫停 |
| Z / C | 音樂倒轉 / 快轉 |
| 空格 | 活動中心 |
| V | 更新日誌 |
| Tab | 隱藏 / 顯示 HUD |
| I | 設定 |
| Esc | 返回 / 關閉當前頁 |

插上手柄會自動適配 Xbox 與 PlayStation 的按鍵圖示，也可以在設定裡手動切換。

---

## 九、小提示

- 可以瀏覽全部活動資料；評論與部分資料只展示一部分。
- 卡片裡的長文字會自動收成一行並顯示省略號，滑鼠移上去會滾動查看。
- 語言、亮度、字型、音量、快捷鍵、視窗大小都會記住，下次打開還是你設定的樣子。
- 視窗標題固定為「FGEXPIG」，工作列圖示就是那隻綠皮豬。是的沒錯，作為本網站與應用程式的創始者，喜歡在糖豆人中穿綠色豬豬裝扮，相信你一定在遊戲中見過綠豬巨星。
