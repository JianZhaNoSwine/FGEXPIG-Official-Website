## 1. Instalacja i uruchomienie

1. Pobierz instalator i klikaj „Zainstaluj” do samego końca — miejsce instalacji możesz wybrać sam.
2. Otwórz FGEXPIG: najpierw pobiera i weryfikuje zasoby (postęp na dole ekranu), a potem wchodzi do **menu głównego** z pokazem tapet.
3. Menu główne ma cztery przyciski: **Main Story** (otwórz stronę), **Website** (oficjalna strona), **GitHub Repository**, **Exit**.
4. Kliknij **Main Story**: odtwarza się animacja otwarcia, a potem pojawia się strona główna. Aby wrócić do menu, wybierz „Wyjdź do menu” w menu w prawym górnym rogu.

## 3. Trzy zakładki

### Sklep (strona wydarzenia)
- **Szczegóły**: chińska nazwa, deweloper, wydawca, data wydania, tagi, liczba wersji; każda wersja i dodatkowa zawartość z nazwą, ceną i wszystkimi kodami map.
- **Osiągnięcia**: kolorowane według rzadkości — Brązowy, Srebrny, Złoty, Platynowy, Fioletowo-złoty, Opalizujący; wydarzenia z grupami trofeów najpierw pokazują przegląd.
- **Recenzje**: oceny mediów (kolorowane według punktów, z rozkładem); kliknij, aby przeczytać pełną recenzję; gdy wydarzenie dzieli się na oryginał / remaster / DLC, przewijaj strony strzałkami w lewo i w prawo.

### Zasoby
- **Przeglądaj / Podgląd**: kliknij element po lewej, duży obraz pojawi się po prawej.
- **Harmonogram**: kalendarz oznacza dni z wpisami; poniżej wszystkie wpisy są wypisane po kolei, z czasem względnym typu „Dzisiaj” i „3 dni temu”.

### Na czasie
- **Tytuły**: pole wyszukiwania + chipy słów kluczowych, poniżej lista postów.
- **Treść / Komentarze**: czytanie treści posta.

## 4. Przełączanie wydarzeń

Każde pole na dole to jedno wydarzenie; wybranie go zmienia tapetę, muzykę i zawartość wszystkich trzech zakładek.

| Wejście | Działanie |
| --- | --- |
| Mysz | Kółko w górę/w dół, przeciąganie z wciśniętym przyciskiem lub kliknięcie ikon po bokach |
| Klawiatura | `A` poprzednie / `D` następne wydarzenie |
| Pad | `LT` / `RT` (Xbox), `L2` / `R2` (PlayStation) |

Gdy wydarzeń jest dużo, naciśnij `Spacja`, aby otworzyć **Centrum wydarzeń** i filtrować według roku lub dewelopera.

---

## 5. Muzyka

- Kliknij okładkę w lewym górnym rogu: odtwarzanie / pauza; przeciągnij pierścień wokół okładki: przewijanie wstecz / do przodu.
- Każde wydarzenie ma własną muzykę, zmienia się razem z wydarzeniem.
- Kliknij tytuł utworu, aby przejść od razu do zakładki „Dźwięk” w ustawieniach i ustawić głośność.

---

## 6. Okno

Proporcje i rozmiar okna są stałe — nie zmienisz ich, przeciągając krawędzie:

| Ustawienie | Wartości |
| --- | --- |
| Proporcje okna | 16:9 / 16:10 |
| Rozmiar okna | Bardzo mały / Mały / Średni / Duży / Bardzo duży |

Zmienia się je strzałkami w lewo i w prawo w „Ustawienia → Interfejs”. W prawym górnym rogu okna są przyciski Minimalizuj i Zamknij.

Naciśnij `I` lub otwórz je z menu w prawym górnym rogu.

| Kategoria | Zawartość |

| Sterowanie | Własne skróty: kliknij pole klawisza i naciśnij nowy klawisz; przy duplikacie klawisze zamieniają się miejscami |
| Dźwięk | Głośność główna, głośność minigier |

## 8. Skróty

| Klawisz | Działanie |
| --- | --- |
| `A` / `D` | Poprzednie / następne wydarzenie |
| `Q` / `E` | Poprzednia / następna zakładka |
| `X` | Odtwarzanie lub pauza muzyki |
| `Z` / `C` | Przewijanie muzyki wstecz / do przodu |

## 9. Wskazówki

- Możesz przeglądać wszystkie materiały wydarzeń; komentarze i część danych są pokazywane tylko częściowo.

- Język, jasność, czcionka, głośność, skróty i rozmiar okna są zapamiętywane: przy następnym uruchomieniu wszystko będzie tak, jak zostawiłeś.
